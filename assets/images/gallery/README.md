# Gallery images

These images were supplied by the repository maintainer for the interactive Gallery examples. They are shared across examples and bundled locally, so the Gallery does not need a network connection to display them.

| Files | Source | Packaged dimensions |
| --- | --- | --- |
| `avatar-01.jpg` through `avatar-06.jpg` | Six supplied square cartoon images | 256 × 256 |
| `neon-red.jpg`, `neon-purple.jpg` | Supplied `3.png` and `4.png` | 1920 × 1080 |
| `lake.jpg` | Supplied landscape illustration | 1182 × 665 |
| `tree.jpg` | Supplied tree photograph | 603 × 1304 |
| `ocean.jpg` | Supplied ocean photograph | 602 × 1305 |

The copies are compressed JPEGs without source photo metadata. Their aspect ratios and visible artwork marks are retained. The two neon illustrations demonstrate sliding between different images, rather than a before-and-after edit of the same scene. The original files are not modified.

The repository's MIT license covers EUI source code; it does not grant additional rights to third-party artwork depicted in these samples.
