# 功能截图 / Feature screenshots

[中文首页](../README.zh-CN.md) · [English project page](../../README.md)

本页截图对应 **EUI 1.3.1**，于 **2026-10-16** 从当前源码构建后采集，统一存放于 [`1.3.1/`](1.3.1/)。每张图片保留完整窗口，包括顶部操作栏、组件导航、左下角实际构建版本和示例区域。

These screenshots show **EUI 1.3.1**, rebuilt from the current source and captured on **2026-10-16**. All images are stored in [`1.3.1/`](1.3.1/). Each includes the complete window, its top bar, navigation, actual build version in the lower-left corner, and examples.

首页展示当前全部分类和精选组件；`1.3.1` 是修复版本，首页不会将旧版本引入的组件标为本版新增。命令面板展示已打开的搜索与命令列表。ECharts 等待图表完成绘制，三维场景等待模型渲染完成；任务看板、图片对比和图片页展示当前示例内容。

The home page shows current categories and featured components. As `1.3.1` is a fix release, components introduced in earlier versions do not carry current-version badges. The command palette is shown open. Charts and 3D models finish rendering before capture; the task board, comparison, and image pages show the current examples.
